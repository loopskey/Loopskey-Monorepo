## هدف

این پوشه نقشه اجرایی بازطراحی رابط کاربری `Course1` بر اساس زبان بصری پروژه قدیمی `../Course` است. مرجع طراحی، پروژه `Course` و مرجع معماری، داده و رفتار، پروژه `Course1` است.

نتیجه نهایی باید ظاهر ساده، خوانا و سازمانی نسخه اول را داشته باشد، بدون آن‌که معماری تمیز نسخه دوم قربانی شود.

> **[قوانین مشترک بازطراحی](./rules.md)**

دو سند بازبینی زیر مرجع تفصیلی‌اند و فقط در صورت ارجاع صریح فاز جاری خوانده می‌شوند:

بنابراین ظاهر `GlassCard` یک‌بار در component مرکزی ساده می‌شود و API آن برای consumerهای موجود ثابت می‌ماند. صف مهاجرت رنگ خام کوچک است و ساخت خانواده موازی Cardهای dashboard مجاز نیست.

## تعریف نهایی موفقیت

- کارفرما در نگاه اول همان حس نسخه اول را دریافت کند: سایدبار آبی با hover/active قوسی، سطح سفید، کارت‌های ساده، border ظریف و چیدمان متراکم‌تر.
- سایدبار زیر `md` به rail عمودی فقط‌آیکون تبدیل شود و از `md` به بالا متن و آیکون را نمایش دهد؛ Bottom Navigation استفاده نشود.
- هیچ tab، deep link، loading/error/empty state یا عملیات فعلی از بین نرود.
- در عرض‌های 375، 768، 1024 و 1440 پیکسل overflow ناخواسته وجود نداشته باشد.
- ناوبری با keyboard و screen reader قابل استفاده باشد.
- chartها با palette سراسری light-only و mapping معنایی ثابت هماهنگ باشند.
- lint، type-check، build و bundle report فرانت پاس شوند.
