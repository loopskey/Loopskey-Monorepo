## Acceptance

- [x] A completed or generating draft refuses chat, patch, CPD patch, reset, discard and generation; a stale AI answer cannot reopen it; the replaced roadmap is no longer editable; a commit never creates a second roadmap for an already replaced one.
- [x] A completed edit session is read-only in the UI with a clear message and a way back to the roadmap; a new edit of the active roadmap still works.
- [x] Each rejected change is explained in the chat with the step or phase title and the reason; valid changes in the same turn are kept; rejected changes never appear in Review.
- [x] Review shows saved draft values with localized labels, never raw codes or the provider's paraphrase.
- [x] Study-time mapping, history, duration and content-less activities inspected; application-side bugs fixed, provider-side behaviour documented.
- [x] Regression tests for every confirmed bug.
