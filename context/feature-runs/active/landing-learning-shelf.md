### Shared content categories

- [x] Courses, events, podcasts, YouTube channels, roadmaps and topic hubs share exactly the 31 supplied categories. The four Prisma enums are identical; a spec fails if they diverge.
- [x] Migration `20261019120000_unified_content_categories` renames `CPD` to `CERTIFICATION` and `OTHER` to `GENERAL` in place, adds the rest, and updates `TopicHub.category`. Run against sample data on an embedded Postgres: all four enums reach 31 values, rows are remapped, the new values are usable after commit.
- [x] The ingestion normalizers share one alias map; `CPD`, `OTHER` and common synonyms (`HR`, `LAW`, `Health & Safety`) still map, unknown values become `GENERAL`. The crawler guide and the four JSON schemas list the 31 values and keep `CPD`/`OTHER` as deprecated aliases.
- [x] `schema.gql` was regenerated by booting the app module (only the four enums changed); front codegen was re-run.
- [x] The 31 covers are in `public/category-art-<slug>.svg` (top level, because every other public path is rewritten to the locale route). Roadmap art uses them, and a card without a picture falls back to its category cover before the kind art.
- [x] The old `roadmap-art-*.svg` files, the old label maps and the `CPD events` label are removed; the four label maps and the hero label are translated in en and fr.
- [x] An old `?category=CPD` or `?category=OTHER` catalogue URL is redirected to the new value.
