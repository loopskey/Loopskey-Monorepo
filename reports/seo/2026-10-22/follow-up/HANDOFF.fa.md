# تحویل اصلاحات SEO

برنچ: `feature/seo-production-follow-up`

تغییرات در پوشهٔ اصلی پروژه قرار دارند. تغییرات ثبت‌نشدهٔ فاز ۲۱ و وضعیت stage آن‌ها حفظ شده‌اند. هیچ commit، push یا انتشار پروداکشن انجام نشده است.

## تغییرات

- نمایش صحیح متن‌های HTML-encoded، مانند `Apply &amp; Interpret`، در خروجی عمومی API؛ جزئیات و فهرست هر چهار نوع محتوا، با زبان مشخص یا بدون آن. شناسه، اسلاگ و دادهٔ قبلی دیتابیس تغییر نمی‌کنند.
- ذخیرهٔ متن ساده برای ورودی‌های جدید پس از حذف HTML؛ خروجی React و JSON-LD همچنان escape می‌شود.
- شناسایی خودکار دامنهٔ بدون `www` به‌عنوان alias دامنهٔ اصلیِ دارای `www`؛ هماهنگی تنظیمات زمان ساخت و اجرا و حفظ مسیر و query در ریدایرکت.
- رندر کارت‌های کاتالوگ در سرور و بارگذاری درخواست‌های خصوصی صفحهٔ اصلی فقط برای نقش مرتبط.
- ابزار `scripts/production-seo-check.mjs` برای کنترل محدود و فقط‌خواندنیِ سایت‌مپ، دو رکورد آزمایشی، ریدایرکت دامنه و مدارک تحویل؛ اتصال آن به کنترل انتشار و مسیر rollback موجود.
- راهنمای عملیات و فایل تحویل برای محتوای واقعی، لینک‌های قدیمی و Search Console؛ اطلاعات ناموجود تأییدشده محسوب نمی‌شوند.

## بررسی‌های انجام‌شده

- ۱۷۵ مجموعهٔ تست واحد API، مجموعاً ۲۵۱۴ تست: موفق.
- دو مجموعهٔ تست یکپارچهٔ GraphQL روی دیتابیس موقت، مجموعاً ۱۴۰ تست: موفق.
- lint و بررسی نوع‌ها در کل پروژه، بیلد فرانت و API: موفق.
- هر ۲۳ مسیر عمومی در محدودهٔ هدف و سقف حجم جاوااسکریپت قرار دارند.
- مرورگر: صفحات انگلیسی و فرانسوی، نبودن نسخهٔ فرانسوی منتشرشده، موبایل ۳۶۰ پیکسل، کیبورد، کاربر مهمان، نقش‌های Provider و Organization و حالت‌های بارگذاری/خالی/خطا/موفق بررسی شدند.
- کنترل‌های داخلی ابزار SEO، سیاست استقرار و ابزارهای شواهد انتشار موفق بودند.

حجم اولیهٔ جاوااسکریپت gzip در بیلد مبنا و بیلد جدید:

| مسیر | قبل، KiB | بعد، KiB |
| --- | ---: | ---: |
| صفحهٔ اصلی | 223.6 | 219.0 |
| کاتالوگ | 180.2 | 177.3 |
| جزئیات دوره | 211.1 | 211.2 |

حجم chunkهای خارج از بارگذاری اولیه از 1607.9 به 1614.1 KiB رسیده است؛ کاهش حجم اولیه به معنی کاهش کل حجم برنامه نیست. فایل‌های `bundle-before.json` و `bundle-after.json` شواهد این اعداد هستند.

مقایسهٔ موبایل با پنج پروفایل سرد برای هر مسیر و هر بیلد، اجرای بومی هر دو بیلد با Next و Node یکسان و API ساختگی یکسان، بدون اجرای هم‌زمان بیلد یا تست:

| مسیر | LCP قبل/بعد، ms | TBT قبل/بعد، ms | CLS قبل/بعد |
| --- | ---: | ---: | ---: |
| صفحهٔ اصلی | 2556 / 2556 | 1398 / 1106 | 0 / 0 |
| کاتالوگ | 1956 / 1984 | 494 / 467 | 0 / 0 |

هدف LCP برابر ۲۵۰۰ و TBT برابر ۲۰۰ میلی‌ثانیه باقی مانده است. هدف TBT در هر دو مسیر و هدف LCP صفحهٔ اصلی محقق نشده‌اند. کاهش TBT صفحهٔ اصلی و کاهش کوچک کاتالوگ، اثبات برآورده‌شدن همهٔ اهداف سرعت نیست. نمونه‌های کامل در `perf-mobile-native-pair.json` ثبت شده‌اند. سنجش قبلیِ ترکیبی Docker/محلی و تلاش ناموفق سندباکس نیز نگه داشته شده‌اند و مبنای این جدول نیستند. این نتایج آزمایشگاهی‌اند و آمار کاربران واقعی یا INP محسوب نمی‌شوند.

## پیش از انتشار

۱. مطابق `docs/seo/publication-quality.md` هویت دو رکورد زیر را با inventory بررسی کنید و از مسیر عادی ادمین رد کنید:

```
crawler-ingest-4c8b043ae6d9cee62fc4edd8
crawler-ingest-616e0bc13633115ede949ec5
```

پس از انقضای کش سایت‌مپ، حداکثر ۳۰۰ ثانیه، هر دو باید ۴۰۴ بدهند و از سایت‌مپ و کارت‌ها خارج باشند. کنترل انتشار جدید در صورت باقی‌ماندن این موارد شکست می‌خورد و مسیر rollback را فعال می‌کند. برای عبور از کنترل، محتوای واقعی را حذف نکنید و کنترل را غیرفعال نکنید.

۲. از مسیر معمول CI و انتشار، API و سپس فرانت را منتشر کنید. تصویر فرانت باید دوباره ساخته شود؛ تغییر env و restart تصویر قدیمی کافی نیست. پراکسی باید Host ورودی را حفظ کند. راهنمای کامل: `docs/seo/production-remediation.md`.

۳. کنترل فقط‌خواندنی پس از انتشار:

```bash
node scripts/production-seo-check.mjs --base-url https://www.loopskey.com --site-origin https://www.loopskey.com --environment production --out technical-seo.json
```

بررسی زندهٔ پیش از انتشار، در `production-technical.json`، هنوز دو رکورد آزمایشی و ریدایرکت دامنه را ناموفق نشان می‌دهد؛ موفقیت کد محلی، اثبات اصلاح پروداکشن نیست.

## موارد نیازمند اطلاعات مالک محتوا

طبق تصمیم شما، مدرک تطبیق چهار لینک قدیمی، اطلاعات ارائه‌دهندهٔ مجاز، محتوای واقعی موضوع و ترجمهٔ فرانسوی و شواهد Search Console در فایل `docs/seo/production-remediation.handoff.json` خالی مانده‌اند. ابزار و گردش‌کار آماده‌اند. اجرای کنترل همراه این فایلِ تکمیل‌نشده عمداً ناموفق است.

این تحویل اثبات ایندکس‌شدن یا رتبهٔ گوگل نیست. بررسی مجدد سایت زنده پس از انتشار انجام می‌شود.
